III

Questions.

What counts as an operator?

A person who runs Orrery, holds credentials, and acts on findings, not a machine and not a service identity. Core is unmetered because it is self-hosted software you run yourself. Hosted plans include a set number of operator seats and let you add more.

What is a box band?

The number of boxes the reconciler is watching across your fleet, whatever the provider or operating system. It is never priced per machine identity or agent; the band is a ceiling on how many boxes one plan covers before you move up.

Is the free core really free forever?

Yes. It is not a trial and it does not expire or get crippled later. It is AGPL-3.0-or-later, zero runtime dependencies, read-only, and identity-free, so you can audit exactly what it does before you ever run it against a real fleet.

What about the AGPL?

The AGPL is a network-copyleft license: if you modify the core and offer that modified version to others over a network, you must make your changes available under the same terms. If that does not work for how you plan to use it, a commercial license is available from Evening Star Productions instead.

Is the hosted plane live yet?

Not yet. The core (reconciler, guards, CLI, deck, self-verifying install) ships today. The governed-autonomy trust layer, the hosted control plane, and the graphical fleet view are in development. Paid plans are open for early access now, so you can talk to us before it lands.

Do you offer nonprofit or education pricing?

Yes. The self-host core is free regardless. Hosted plans are discounted for nonprofits and education, and if you cannot pay at all, tell us that directly.
